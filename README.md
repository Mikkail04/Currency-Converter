# Currency Converter

🔗 Live Demo: https://currencyconversiontool.vercel.app/

Full-stack currency conversion application built with:

* Spring Boot (Java)
* React (Vite)
* H2 Database
* Frankfurter API

## Features

* Live currency conversion
* Multiple currency support
* Currency swap functionality
* Conversion history
* Delete conversion history
* Input validation
* Error handling
* REST API
* Swagger API documentation
* Responsive UI

## Setup

### Backend

1. `cd demo`
2. `.\mvnw.cmd spring-boot:run`

Backend runs on:

`http://localhost:8081`

### Frontend

1. `cd currency-frontend`
2. `npm install`
3. Create a `.env` file:
   `VITE_API_URL=http://localhost:8081`
4. `npm run dev`

Frontend runs on:

`http://localhost:5173`
